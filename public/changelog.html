Release notes

Changelog

What’s new in MILO for iOS and on askmilo.pro. MILO is live on the App Store — updates ship as new versions are released.

1.2.0

App Store

October 2026 · iOS 17.6+

Use your own OpenAI-compatible server and any model ID your provider offers, and see each provider’s official logo.

Added

  • Your own server — connect an OpenAI-compatible server over HTTPS by entering its address and exact model ID, with an optional API key. MILO asks your permission before it sends that server your prompts.
  • Any model ID — pick a suggested model or type any model ID your provider offers, in chat or Settings. MILO keeps your choice after restarts and updates.
  • Official provider logos — in onboarding, the model picker, chat, History, Settings and Help, sized to match your text. VoiceOver now says which model filter is selected.

Improved

  • Web search when you ask — with web search on (Brave, Tavily or TinyFish), ask MILO to search the web in your message (for example, “search the web for…”). It no longer searches on its own.
  • Clearer errors — when a request fails, Settings, chat and Siri, including Siri in CarPlay, tell you whether to check your API key, model, account access or billing. Error messages no longer show the provider’s raw response.

Fixed

  • Newer Claude models — including ones you enter by ID, now use Claude’s default creativity setting, and Settings shows when the temperature control doesn’t apply.

After you update

  • If you use a cloud AI provider, open MILO and allow AI Data Sharing again. Until you do, Siri asks you to open the app instead of answering.

Download on the App Store · Report issues on GitHub.

1.1.0

App Store

September 2026 · iOS 17.6+

Easier to use with VoiceOver and larger text, long chats keep working, and your keys and conversations are handled more carefully.

Added

  • Web search — optional current web results from Brave, Tavily or TinyFish when you turn it on in Settings → Tools.
  • Conversation mode — choose Session (follow-ups remember context) or One-shot (each question stands alone).
  • Accessibility — VoiceOver names every chat button, and text follows your Dynamic Type size.

Fixed

  • Long conversations stay within the model’s context window instead of failing to send.
  • If local chat storage is damaged, MILO explains what happened and lets you reset instead of quitting on launch.
  • API keys are saved more safely and stay on this device; chat content is no longer written to device logs.
  • Cloud AI is used only after you agree for the provider that will actually handle the request.
  • Claude Opus 4.7 and 4.8 work again, and history search is faster.

Download on the App Store · Report issues on GitHub.

1.0.0

App Store

June 2026 · iOS 17.6+

First public release: hands-free Siri to the model you choose, with CarPlay-friendly answers and on-device history.

Added

  • Siri bridge — “Hey Siri, ask MILO…” from lock screen, headphones, or CarPlay.
  • Seven providers — OpenAI, Anthropic, Google Gemini, Mistral, Groq, OpenRouter (200+ models), and Apple Intelligence. Local Ollama is coming soon and was not included in 1.0.
  • Voice model switching — change provider or model mid-conversation without opening the app.
  • CarPlay mode — shorter, spoken answers tuned for driving.
  • On-device history — searchable threads with tokens, latency, and estimated cost per conversation (SwiftData).
  • Provider settings — per-model temperature, max tokens, and system prompts.
  • API key management — keys stored locally and encrypted in the iOS Keychain.
  • Help & Guide — built-in Siri phrase examples and sidebar navigation.

Download on the App Store · Report issues on GitHub.
