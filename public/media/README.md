# Founder clip assets (#24)

This directory is the drop slot for the founder video/voice clip requested by
<https://github.com/luongnv89/milo-website/issues/24>. Full procedure:
`docs/founder-clip.md`.

Expected filenames (referenced by `founderStory` in `src/data/content.js`):

- `founder-clip.mp4` — the real ~20–30 s founder-recorded clip ("Hey Siri, ask MILO" flow)
- `founder-clip.m4a` — voice-only alternative
- `founder-clip.vtt` — English WebVTT captions (required with video)
- `founder-clip-poster.jpg` — optional poster frame

Do NOT commit AI-generated, stock, or otherwise fabricated media here — the
clip must be a genuine recording of the founder. `public/milo-promo-portrait-final.mp4`
is a Remotion-rendered promo, not a founder clip, and must not be reused as one.
