Common setup questions

  • Cloud AI needs your own API key. Add one in Settings → API Keys for Gemini, Claude, OpenAI, Mistral, Groq, or OpenRouter. Apple Intelligence (on-device) and Ollama (local) do not need a cloud key.
  • Siri: say “Hey Siri, ask MILO …” after enabling Siri for MILO in iOS Settings.
  • AI Data Sharing: MILO asks before sending prompts to a cloud provider. Review or revoke this in Settings → AI Data Sharing.
  • Web search is off by default. Turn it on in Settings → Tools only after you add a Brave, Tavily, or TinyFish key.
